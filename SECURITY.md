# Security Policy

Security fixes are provided for the latest release.

Report suspected vulnerabilities with **Report a vulnerability** in the
repository's Security section.
Do not open a public issue for a suspected vulnerability and do not include
credentials, private router configuration, wireless settings, or identifying
client data in any report.

If the private reporting form is unavailable, do not disclose exploit details
publicly. Open a non-sensitive issue asking for a private contact channel
without including vulnerability details.
